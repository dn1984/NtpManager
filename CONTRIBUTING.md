# Правила участия

Спасибо за интерес к проекту. Утилита работает с системными настройками службы времени, поэтому
главное требование к изменениям — **предсказуемость и проверяемость**: любая правка должна быть
безопасна для чужого сервера и подтверждена фактическим запуском.

## Что приветствуется

- исправления ошибок с описанием воспроизведения;
- улучшения диагностики (новые понятные строки состояния, пояснения, что делать);
- поддержка других версий Windows и языков интерфейса;
- уточнения документации (README.md — русский, README.en.md — английский).

## Требования к коду

Файл `NtpManager.ps1` должен оставаться совместимым с **Windows PowerShell 2.0**
(Windows Server 2008 R2 — целевая система):

- **не использовать**: `$PSScriptRoot`, `Get-Content -Raw`, `ConvertTo-Json` / `ConvertFrom-Json`,
  `[pscustomobject]`, `[Type]::new()`, `Get-CimInstance`, `Test-NetConnection`, `Get-NetFirewallRule` /
  `New-NetFirewallRule`, `-in` / `-notin`, операторы `-shl` / `-shr`, `Add-Member -NotePropertyName`,
  `Get-ChildItem -File`, тернарный оператор;
- **файл обязан оставаться в кодировке UTF-8 с BOM** — иначе PowerShell 2.0 прочитает русский текст
  как ANSI и скрипт не запустится. При правке в редакторе выбирайте «UTF-8 с BOM»;
- **файлы `*.cmd` — только ASCII** (cmd.exe выводит текст в OEM-кодировке), все сообщения на русском
  печатает сам PowerShell-скрипт;
- изменения реестра выполняются только в ветвях `Services\W32Time` и (по явной команде)
  `Policies\Microsoft\W32Time`; перед любым изменением должна создаваться резервная копия;
- новые строки состояния должны иметь понятный вердикт: что не так и что делать;
- **любая новая строка интерфейса должна быть добавлена в словарь перевода**: элементы окна и
  заголовки таблицы — в `$script:EnUi`, подсказки — в `$script:EnTips`, составные строки состояния,
  журнала и отчёта — во фрагменты `$script:EnParts`. Без этого строка просто останется русской
  в английском режиме (утилита не падает, но перевод будет неполным).

## Как проверить правку

1. **Разбор синтаксиса в двух движках** (обе команды должны дать `SYNTAX: OK`):

   ```powershell
   powershell.exe -Version 2 -NoProfile -ExecutionPolicy Bypass -File .\verify\Parse-Check.ps1 NtpManager.ps1
   powershell.exe            -NoProfile -ExecutionPolicy Bypass -File .\verify\Parse-Check.ps1 NtpManager.ps1
   ```

2. **Отчёт без прав администратора** — ничего не должен менять в системе:

   ```cmd
   NtpManager.cmd -Report
   ```

   Код возврата 0/1/2 — нормально; 3 — ошибка запуска.

3. **Раскладка окна** — проверка наложений элементов (в тестовой среде) и визуальный осмотр.

4. **Дымовой тест в CI** выполняется автоматически на `windows-latest`
   (см. `.github/workflows/syntax-check.yml`): разбор синтаксиса, проверка BOM и запуск `-Report`.

Обязательно укажите в описании изменения: что именно проверяли, какими командами и что получили.
Если что-то проверить не удалось (например, запись в реестр из-за отсутствия прав администратора) —
честно напишите это в описании, а не умалчивайте.

## Коммиты и pull request

- Сообщения коммитов — в повелительном наклонении, по-русски или по-английски, с указанием области:
  `port: определять владельца порта по составу служб`, `docs: дополнить FAQ про политику`.
- Один pull request — одна логическая правка.
- При изменении поведения обновляйте `CHANGELOG.md` (раздел `Unreleased` или новая версия)
  и, при необходимости, оба README.
- Версия утилиты хранится в `$script:Ver` в начале скрипта.
